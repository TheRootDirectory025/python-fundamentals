# Python Fundamentals

A structured and practical collection of Python fundamentals and core concepts, created as part of my journey toward professional backend development.

This repository focuses on understanding Python through practical examples, organized code, and backend-oriented use cases.

---

## About

This repository covers Python from fundamental syntax and data structures to more advanced concepts such as object-oriented programming, decorators, type hints, testing, and dependency management.

The goal is not only to learn Python syntax, but also to build a strong foundation for working with frameworks such as Django and Django REST Framework.
